# 常用经营报告驱动的修订方案

更新时间：2026-04-16

## 背景

已阅读 `C:\Project\HotelAgent\report` 下 4 份常用经营/资管报告：

- `2024年资管财务审计部工作汇报（2025.1.23）谢总(1).pdf`
- `2025年1-6月国际品牌酒店经营表现（0717）(1).pdf`
- `资管中心汇报 - 2025年一季度汇报FIN(2).pdf`
- `资管中心汇报 - 汇报.pdf`

这些报告说明，管理层日常使用的“经营分析”不是单指标问答，而是围绕公司全集、品牌组合、资产包、区域、单店和异常酒店展开的报告式经营穿透。

## 核心发现

1. `富力所有酒店` 在业务语义上表示公司旗下全部酒店，不是酒店名称包含“富力”的酒店。
2. 经营情况默认不是单一经营利润，而是一组指标：总收入、NOP/经营利润、NOP率、维修储备金、客房收入、餐饮/宴会收入、ADR、OCC、RevPAR、人工、食材、能耗、固定成本、运营管理成本。
3. 对比口径通常同时包含实际、预算、去年同期、2023、2019、月度趋势和全年预测。
4. 管理层表达高频使用组合拆解：公司全部酒店、万达品牌、国际品牌、国际-原万达、国际-自建、自建酒店、区域、资产包。
5. 报告大量使用排名和分层：总收入前十、NOP前十、ADR前十、RevPAR前十、OCC前十、NOP梯队、亏损酒店、预算完成后位、能耗超预算且收入未完成名单。
6. 收入端分析强调结构和驱动：客房、餐饮、宴会、商务会议、婚宴、其它收入，以及量价关系。
7. 成本端分析强调占收入比和异常交叉条件：人工、食材、能耗、固定成本、运营管理成本。
8. 外部行业对标应作为可选增强，需标注来源、口径和时效。

## 目标形态

从：

```text
用户问题 -> 指标识别 -> SQL -> 单指标解释
```

升级为：

```text
用户问题 -> 经营场景识别 -> 报告模板选择 -> 多指标取数 -> 结构拆解 -> 排名/梯队/异常 -> 管理层经营观察
```

## 修订方案

### 1. 语义层

- 将公司主体词纳入根范围：富力、富力集团、公司、集团、本公司、全公司。
- 为常用报告组合建立实体别名：万达品牌、国际品牌、国际-原万达、国际-自建、自建酒店、兆晞资产包。
- 将“经营情况/经营表现/业绩情况”识别为经营报告场景，而不是单指标场景。
- 识别报告动作：总览、同比、预算完成、排名、梯队、亏损、成本异常、收入结构、预测。

### 2. 查询层

- 组合类问题默认取宽表中的完整经营驾驶舱字段。
- 除聚合值外，同步取组合明细，用于排名、梯队和异常样本。
- 增加交叉异常查询：收入未达预算且能耗超预算、利润为负、ADR/OCC 双降、成本率上升。
- 保留外部行业对标开关，联网或外部数据源未接入时只返回内部对标和待补充说明。

### 3. 解释层

- 对组合类问题采用报告式章节：
  - 分析范围
  - 经营总览
  - 收入质量
  - 客房效率
  - 利润质量
  - 成本效率
  - 重点酒店与梯队
  - 横向对标与继续追问
- 输出以客观数据拆解为主，不直接给“好/坏”结论。
- 使用管理层熟悉表达：量价关系、收入结构、利润转化、成本占收比、拖累/拉动、梯队、异常样本。

### 4. 前端层

- 默认隐藏技术页签，仅保留管理层阅读所需内容。
- “你可以继续问”优先显示报告式追问：经营摘要、收入结构、利润成本效率、重点酒店、亏损酒店、切同比、切预算。
- 筛选建议根据问题类型生成：公司/组合问题优先品牌、区域、重点酒店、月份、摘要。
