# 第 27 轮执行记录：前端管理层视图与调试视图分层

更新时间：2026-04-19

## 1. 本轮目标

本轮推进 R5.1：管理层视图与调试视图分层。

目标是在默认演示和管理层使用场景中减少技术信息干扰，同时保留研发、交付和排障需要的 Trace、SQL、权限、结构化数据和系统配置。

## 2. 本轮完成内容

### 2.1 新增视图模式

前端新增 `ViewMode`：

- `management`：管理层视图，默认只展示经营结论、关键指标、分维度汇总、重点酒店和追问入口。
- `debug`：调试视图，展开技术诊断、Trace、SQL、权限范围、结构化数据、模型配置和回答模板。

集团管理层默认进入管理层视图；非集团角色默认进入调试视图，方便交付调试。

### 2.2 高级设置增加视图切换

在高级设置中新增“视图模式”切换按钮：

- 管理层视图
- 调试视图

切换到调试视图后，已有详情面板立即可见，不需要切换角色。

### 2.3 前端回归测试

新增测试：

- `集团默认管理层视图，可切换调试视图查看技术细节`

覆盖：

- 集团默认不显示技术诊断与 SQL 计划。
- 打开高级设置后可看到“管理层视图”。
- 点击后切换为“调试视图”。
- 技术诊断与 SQL 计划可见。

同时更新原有高级设置测试，确认集团默认视图模式为“管理层视图”。
