# 第 28 轮执行记录：集团层经营简报结构重排

更新时间：2026-04-20

## 1. 本轮目标

把“公司全部酒店 / 管理公司 / 区域”这一类集团层问题的默认输出顺序，调整为更贴近真实管理汇报的阅读节奏。

这轮不再沿用“先组合、再酒店、再补结构”的旧顺序，而是改为：

- 先看整体结论
- 再看集团核心指标
- 再拆管理公司和区域结构
- 再做收入、房务、利润、成本归因
- 最后再下钻重点酒店与管理动作

## 2. 本轮调整

### 2.1 管理层组合模板顺序调整

`executive_portfolio` 模板更新为：

- 分析范围
- 组合经营摘要
- 经营总览
- 管理公司/区域汇总
- 收入质量
- 客房效率
- 利润质量
- 成本效率
- 重点酒店与梯队
- 横向对标与继续追问

这样集团层问题不会再一上来先落到单店名单，而是先完成“大盘判断”和“结构拆分”。

### 2.2 组合模板允许补结构层

原来只有 `group_by_dimension_report` 模板会显式展示 `管理公司/区域汇总`。

本轮调整后，只要组合问题链路已经拿到了管理公司或区域分组结果，`executive_portfolio` 也会在总览后补出结构层摘要，避免管理层必须额外追问一次“按管理公司和区域拆开看”。

### 2.3 前端管理层视图排序同步

前端管理层视图的章节优先级同步调整：

- 先显示摘要类章节
- 再显示经营总览和管理公司/区域汇总
- 再显示归因类章节
- 单店观察后移

页面标题也更明确地对齐“管理层经营简报”语境，而不是偏技术或偏组合分析的标签。

## 3. 设计原则

集团层总汇总类问题的标准阅读路径统一为：

1. 大盘判断：整体收入、利润、利润率同比或预算表现。
2. 结构拆分：国际品牌 vs 万达酒店，区域与子品牌拆解。
3. 经营归因：客房、餐饮、OCC、ADR、RevPAR、利润和成本变化。
4. 单店穿透：重点酒店、问题酒店、异常酒店横向比较。
5. 管理输出：亮点复制、问题整改、下月重点跟踪方向。

## 4. 本轮价值

- 集团管理层更容易先形成整体判断，再决定是否继续下钻。
- “国际品牌 vs 万达酒店”“区域结构差异”被前置，结构洞察更符合汇报习惯。
- 单店异常不再抢占首屏，阅读节奏更稳。

## 5. 后续建议

- 继续把 `管理公司/区域汇总` 细化为“管理公司对比”与“区域对比”两个独立 section。
- 增加“管理建议 / 重点改善方向”独立章节，减少建议散落在追问区。
- 对集团层问题默认隐藏系统痕迹字段，如“当前理解”“技术标签”“缓存说明”。
