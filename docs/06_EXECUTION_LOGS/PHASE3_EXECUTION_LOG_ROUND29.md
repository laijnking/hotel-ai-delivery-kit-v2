# 第 29 轮执行记录：单店经营简报结构重排

更新时间：2026-04-20

## 1. 本轮目标

把单店问题的默认输出从“指标快照 + 分散解释”调整为更接近总经理月度复盘的固定结构：

- 经营结果
- 问题归因
- 横向对比
- 结论

## 2. 本轮调整

### 2.1 单店模板主结构调整

`executive_hotel_snapshot` 模板默认章节顺序改为：

- 分析范围
- 经营结果
- 问题归因
- 横向对比
- 结论
- 收入质量
- 客房效率
- 利润质量
- 成本效率

其中前五段作为管理层首屏结构，后四段继续保留为归因证据层。

### 2.2 经营结果固定四项

单店 `经营结果` 统一展示：

- 总收入：实际 / 预算 / 同比
- 业主利润：实际 / 预算 / 同比
- 利润率：实际 / 预算 / 同比
- RevPAR：实际 / 预算 / 同比

### 2.3 问题归因固定三类

`问题归因` 固定按三类拆解：

- 客房：ADR、OCC、RevPAR、客房收入、客房利润
- 餐饮：餐厅收入、宴会收入、餐饮利润
- 成本：人工、能耗、行政费用

### 2.4 横向对比与结论固定输出

`横向对比` 固定保留三层：

- 集团内同区域排名
- 集团内同档次对比
- 外部同行市场对比

`结论` 固定输出三句话：

- 一句话经营判断
- 两个核心问题
- 三个改进动作

## 3. 本轮价值

- 单店回答更像酒店总经理月报，而不是技术化指标快照。
- 管理层先看结果和问题，再决定是否继续看细分证据。
- “判断 + 问题 + 动作”被固定下来，输出风格更稳定。
