# 第 30 轮执行记录：集团层管理建议接入 LLM 推理

更新时间：2026-04-20

## 1. 本轮目标

把集团层与分维度汇总问题也升级成与单店一致的双层模式：

- 事实层：继续由规则和确定性数据生成
- 建议层：由大语言模型在事实约束下生成管理结论

## 2. 本轮调整

### 2.1 集团模板新增结论 section

为以下模板补充 `结论` section：

- `executive_portfolio`
- `executive_group_dimension`

当前章节结构保持不变，只在末尾增加管理结论层，不打乱既有的总览、结构、归因和单店观察顺序。

### 2.2 LLM 只接管结论，不重写事实层

本轮没有把整份集团报告交给模型改写，而是约束为：

- `summary` 继续只写客观事实
- `收入质量 / 客房效率 / 利润质量 / 成本效率 / 管理公司区域汇总` 继续沿用确定性文本
- 只有 `结论` section 允许由 LLM 生成

这样可以避免模型把真实取数字段、章节顺序或技术兜底说明改坏。

### 2.3 集团层结论输出要求

集团层 `conclusion` 允许做管理推理，但必须基于已返回事实，且至少包含：

- 整体判断
- 两个核心问题
- 三个优先动作

如果模型未返回，则继续使用规则生成的兜底结论。

## 3. 本轮价值

- 集团层建议不再只是规则拼接，开始具备管理层口径的推理能力。
- 报告主体仍然保持稳定、可追溯、可解释。
- LLM 影响面被限制在结论层，降低了结构回退风险。
